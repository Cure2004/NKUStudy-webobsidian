## 第4步需要明确的事项

本轮文档验收和第4步实施授权是两件事；本交接不自动启动改代码或部署。无争议的解析、最终路径和初始化安全修复不必等待全部产品选择。

对应功能开始前集中确认：

1. 谁可编辑：匿名写还是登录后投稿。
2. 内容边界：阅读整个内容根还是指定目录；草稿是否共享；附件允许根、格式和额度。
3. 目标矩阵：独立Wiki、内容根、edit分支、PR base和发布分支。未知时用本地bare/mock，不猜main。
4. 审核规则：是否必须PR、谁合并、PR失败时如何提示和查询已发生的push结果。
5. 图片方案：本地附件或外部图床，及失败回退策略。
